DEPLOY (Netlify):
1. Is folder ko GitHub repo mein push karein -> Netlify > Add new site > Import from Git (ya: npm i -g netlify-cli; netlify deploy --prod)
2. Netlify > Site settings > Environment variables: ADMIN_PASSWORD = (apna strong password)
3. Admin: https://YOURSITE.netlify.app/admin
Data (orders/products) Netlify Blobs mein permanently save hota hai.
